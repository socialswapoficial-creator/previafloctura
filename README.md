# Paraíso das Flores

Site institucional em HTML, CSS e JavaScript, com imagens, vídeos e animações.

## Hospedar

Na Vercel, importe este repositório. Framework: Other; diretório de saída: `dist`; sem comando de build ou instalação. O arquivo `vercel.json` define a saída.

Para manutenção, edite os arquivos legíveis em `dist` e execute `python scripts/package-static.py` para atualizar o bundle e o CSS versionados.

O envio inicial verifica SHA-256 de todos os arquivos baixados e registra o resultado em `transfer-verification.json`.
